# AquaAudit — Local Storage Prototype

This version saves water usage records, wastage reports, and the daily target in the browser's localStorage. No Supabase, Firebase, login, API key, or backend server is needed.

## Run in VS Code
1. Extract this ZIP.
2. Open the `AquaAudit_Local_Storage` folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Add a water usage record, refresh the page, and confirm the record remains.

## Features
- Add, edit and delete water usage entries
- Today's totals and daily target progress
- Search and date filters
- Usage charts and insights
- Wastage concern log and status updates
- CSV export and print report

## Important
Data is saved only in this browser on this device. Clearing browser site data may erase it. Different browsers/devices have separate storage. Chart.js is loaded from a CDN, so an internet connection is needed for charts.
